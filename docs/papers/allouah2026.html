Allouah et al. (2026)

你的 AI 代理在買什麼？代理式電商中的選擇偏誤與模型依賴

What Is Your AI Agent Buying? Evaluation, Biases, Model Dependence, & Emerging Implications of Agentic E-Commerce

出處

ONE-LINE SUMMARY

作者讓 Claude、GPT、Gemini 在模擬商城替人買東西，發現不同模型選出的「市占」差很多，而且都偏好第一排；「贊助」標籤讓被選機率從 10% 降到 8%–9%，「平台推薦」標籤則拉高到 20%–43%。

研究問題研究方法主要發現限制與未來方向

研究問題

重點

AI 代理會買什麼、為什麼買？分成「市占長什麼樣」與「對各種屬性和平台槓桿怎麼反應」兩層。

研究問題（Section 1, p. 8697）

  • RQ1：當購買完全由 AI 代理中介時，各商品的市占率如何？不同 AI 代理之間差多少？
  • RQ2：AI 代理如何回應可觀察的商品屬性（價格、評分、評論數、文字）與平台槓桿（版位、促銷、贊助）？

研究目的

  1. 建立一個「經濟評估框架」，而不是有標準答案的排行榜：購物沒有唯一正確的商品，重點是量出代理的選擇傾向（Section 1, p. 8698）。
  2. 用隨機化實驗取得因果估計，隔離出「選擇」這一步，不測整段購物流程的任務完成度。
  3. 提出對平台、賣家、消費者與監管者的具體意涵。

研究方法

實驗環境：ACES（Agentic e-CommercE Simulator）

  • 組成（Section 2, p. 8698）：
    • 不綁定廠商的瀏覽器代理：視覺語言模型（VLM）＋工具呼叫，以 LangChain 與 Selenium 實作。
    • 完全可控的模擬電商網站（mock-app），搜尋結果以 2×4 格子呈現 8 個商品。
  • 流程：開啟網站 → 截圖 → 用通用預設提示詞詢問模型 → 記錄選擇。沒有商品詳細頁，刻意不做深層瀏覽，以隔離「選擇」這一步。
  • 商品：8 個品類（健身手錶、iPhone 16 Pro 手機殼、滑鼠墊、辦公檯燈、釘書機、衛生紙、牙膏、洗衣機），每類取 Amazon.com 上 8 個代表性商品。
  • 開源：程式碼公開於 GitHub（mycustomai/ACES）。

實驗一：完全委託下的市占率

  • 每個品類跑 1,000 次，只隨機排列商品位置，其他屬性維持 Amazon 原始資料（Section 3, p. 8698）。
  • 以各商品被選中的比例作為「完全委託世界」中的市占率代理指標。
  • 模型：Claude Sonnet 4、GPT-4.1、Gemini 2.5 Flash。

實驗二：隨機對照實驗估計選擇敏感度

  • 每個品類產生 500 個情境，同時隨機化版位、三種標籤、價格、評分與評論數（Table 1, p. 8699）。
  • 擾動幅度刻意設在「足以影響選擇、但不改變整體商品樣貌」的範圍。
  • 估計方法：條件 Logit，跨品類合併估計，含商品固定效果。
  • 樣本：觀察值 25,802 / 25,066 / 25,215；選擇集 3,756 / 3,931 / 3,953；Pseudo R² 0.44 / 0.51 / 0.42（Claude / GPT / Gemini，Table 2）。

穩健性檢驗（Section 4, p. 8700）

  • 無介面（Headless）環境：改成純文字、排序過的 JSON 清單（無圖片），模擬代理透過 API 讀取商品目錄。
  • 提示詞變體：「忽略位置」、「忽略位置並優先考慮價格」，在兩種介面都測試。

主要發現

重點

AI 代理不是中立的完美比價者：它們有明顯的版位偏誤、會懲罰廣告、相信平台推薦，而且每個模型的偏好都不一樣，同一組商品換個模型，市占就大幅改變。

換一個模型，市占就不一樣

  • 同一組健身手錶，Claude Sonnet 4 有 45% 選 Fitbit Inspire，GPT-4.1 與 Gemini 2.5 Flash 只有約 25%（Figure 1, p. 8698）。
  • 有些品類的選擇集中在少數商品，部分品牌從未被選中（例如釘書機中的 Amazon Basics 與 Arrow）。作者指出這可能造成市場集中，壓縮消費者原本分散的偏好，也讓品牌難以維持能見度（Section 3, p. 8698）。

版位很重要，但「哪裡最好」因模型而異

  • 三個模型都明顯偏好第一排（Table 2）。
  • 欄位偏好卻各不相同：GPT-4.1 強烈偏好第 1 欄；Claude Sonnet 4 幾乎忽略第 1 欄、偏好中間兩欄；Gemini 2.5 Flash 偏向第 3、4 欄（Section 4, p. 8699）。所以不存在通用的「最佳版位」。
  • 以 Claude Sonnet 4 為例：一個在右下角只有 4.5% 被選機率的商品，移到第一排第 2 或第 3 欄，被選率增加 5 倍；移到左上角只有一半的效果（p. 8699）。

「贊助」被打折，「平台推薦」被當真

  • 基準被選機率 10% 的商品，加上 Sponsored 標籤後降到 8.9% / 8.0% / 7.9%（Claude / GPT / Gemini）（p. 8699）。
  • 加上 Overall Pick 推薦標籤後升到 24.3% / 19.9% / 42.6%（p. 8699）。
  • 稀缺標籤效果微弱為負，或與零無顯著差異。
  • 因為標籤是隨機分配的，這些是因果效果，不是商品本身品質造成的假象。

對價格、評分、評論數的方向合理，但幅度差很多

  • 三者都偏好便宜、高評分、評論多的商品，方向和理性購物者一致（p. 8699）。
  • 評分 +0.1 時，10% 基準機率升為 15.4% / 20.3% / 16.0%（Claude / GPT / Gemini）（p. 8699）。
  • 價格彈性約 −1.6 到 −2.2，和人類購物者在品牌／單品層級的價格彈性估計大致相近（p. 8700）。

換算成「可以多賣多少錢」

在不流失市占的前提下，賣家可以漲價的幅度（Section 4, p. 8700）：

改變 Claude Sonnet 4 GPT-4.1 Gemini 2.5 Flash
從第二排移到第一排 約可漲一倍 約可漲一倍 約 +17%
獲得 Overall Pick +92% +65% +138%
評分 +0.1 約三分之一 67% 約四分之一
評論數加倍 +19% +37% +17%

換成 API 或改提示詞，偏誤仍在

  • 無介面環境：排序越前面的商品權重越大，各模型有自己的「峰值」位置（Claude 與 GPT 是第 1 名，Gemini 是第 3 名）；Overall Pick 加分、Sponsored 扣分依然存在。代表偏誤不是視覺造成的（p. 8700）。
  • 提示詞：「忽略位置」幾乎無法消除版位效果；「忽略位置並優先考慮價格」會讓價格敏感度變高、推薦標籤影響變小，但仍殘留版位偏誤（p. 8700）。作者結論：要消除版位偏誤，可能需要設計層面的介入，光靠指令不夠。

賣家端代理可以搶市占（僅簡述）

  • 作者提到另做了實驗：賣家端代理只要稍微修改商品描述、針對買方 AI 的偏好調整，就能取得可觀的市占增加；但因篇幅限制未列出細節（Section 5, p. 8700）。

限制與未來方向

研究限制

  • 簡化的購物流程：只有搜尋結果頁、沒有商品詳細頁，省略完整漏斗，只能視為選擇行為的一階近似（Section 2, p. 8698）。
  • 只測三個模型：Claude Sonnet 4、GPT-4.1、Gemini 2.5 Flash，結果會隨模型版本改變。
  • 商品與情境有限：8 個品類、每類 8 個商品，使用通用的預設提示詞。
  • 沒有人類基準：作者承認是否應與人類行為對照是重要問題，但本研究先專注建立評估框架（Section 5, p. 8700）。

未來研究方向

  1. 與人類消費者基準做校準比較。
  2. 賣家端代理如何針對買方代理最佳化，以及雙方代理互動的市場後果。
  3. 設計層面的去偏誤介入，例如針對代理的排名與版面政策。
