## 為什麼做這本手帳

以前讀一篇論文要經過很多手：先把 PDF 存進 Zotero，丟到 NotebookLM 整理大綱，再請 Claude 改成白話，最後貼進 Obsidian。每一篇都要重複一次，格式也常常不一樣。

這本手帳把流程收斂成一句話：**「整理這篇」**。AI 依照專案裡的 `CLAUDE.md` 規則，直接讀 Zotero 裡的 PDF、寫出固定格式的筆記，再更新這個網站。

## 一篇論文怎麼變成一頁

1. **找論文：** `find_paper.py` 從 Zotero 查出書目與 PDF 位置，書目資料一律以 Zotero 為準。
2. **寫筆記：** AI 讀完全文，依範本寫成精讀筆記，每個數字都要標頁碼或表號。
3. **挑公開段落：** `sync_notes.py` 只取出一句話總結、研究問題、研究方法、主要發現與限制。
4. **建置網站：** `build.py` 套用網站版型，並檢查有沒有私人字詞或壞掉的連結，沒通過就不發布。

## 規則寫在哪裡

所有規則都在 repo 的 `CLAUDE.md`：專案目的、筆記格式、「說人話」的標準、公開邊界、視覺風格、命名方式，以及 AI 可以和不可以做的事。

新增論文時只要在 Claude Code 輸入 `/add-paper 關鍵字`，AI 就會照著同一套規則完成。之後讀到其他領域的論文，只要在設定裡新增主題，就能用同一套流程收進來。

## 閱讀時請注意

- 這裡是個人讀書筆記，不是原文，引用前請回到論文確認。
- 每篇只公開部分段落，完整論證與數據請閱讀原文。
