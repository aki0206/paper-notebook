## 研究問題

> [!success] 重點
> 建立全球首個針對 GEM 廣告植入回答（AIR）的綜合評測基準 **GEM-Bench**（3 個真實資料集 × 滿意度／參與度兩大評測維度），並提出多 Agent 框架 **Ad-LLM**，驗證不同廣告植入方案在回答品質、使用者信任、點擊率與運算成本之間的取捨。

### 四個核心研究問題（Section 4, p. 6）

- **RQ1**：各種 AIR 生成方案，在定量（相似度為基礎）與定性（LLM-as-a-Judge）指標下表現如何？
- **RQ2**：真人對 AIR 生成回答的反應如何？人類評估與 LLM 評審的一致性有多高？
- **RQ3**：Ad-LLM 框架中的核心 Agent，用不同實現方式（例如 Prompt-based vs. Response-based 檢索、有無 Rewriter）會如何影響生成效果？
- **RQ4**：不同方案在等待時間與 Token 費用（財務成本）上的負擔各是多少？

## 研究方法

### 研究設計
基準測試構建（Benchmark Curation）、多 Agent 系統開發、LLM-as-a-Judge 自動化審核、真人使用者實驗（User Study）、消融實驗（Ablation Study）與成本分析。（Section 3、4，p. 4–8）

### 樣本來源與樣本數

| 資料集 | 來源與規模 | 出處 |
| :--- | :--- | :--- |
| **MT-Human** | 來自 MT-Bench 人文類別的 10 個首輪查詢，對應 6,556 個廣告商品 | Section 3.1, Table 1, p. 4–5 |
| **LM-Market** | 來自 LMSYS-Chat-1M，經過濾與聚類，保留 1,701 個高廣告植入潛力查詢（旅遊、食譜、軟體），對應 6,556 個廣告商品；評估時採樣 100 個查詢，擴展測試至 1,000 個查詢 | Section 3.1, Table 1, p. 4–5；Section 4, p. 5 |
| **CA-Prod** | 來自真實商業搜尋引擎的點擊資料集，含 120 個查詢與 2,215 個商品（涵蓋營養補充品、女性服飾等 6 大領域），模擬 AI Overview | Section 3.1, Table 1, p. 4–5 |

**人類實驗樣本**：招募 **118 位**參與者，評估 20 個查詢與 40 組（查詢–回答）配對，回收 **157 份有效問卷**、共 **3,140 個真人評分**（平均每個項目獲得 65 個獨立評價）。（Section 4.2，p. 6）

### 模型設定

- **預設 Base LLM**：doubao-1.5-lite-32k（另用 llama3.3-70B、qwen3-30b-a3b、gemini-2.0-flash-lite、gemini-2.5-flash-lite 做驗證）
- **預設 Judge Model**：gpt-4.1-mini（另用 qwen-max、claude-3.5-haiku、kimi-k2 驗證一致性）
- **Embedding 模型**：預設 text-embedding-3-small，消融實驗對比 all-MiniLM-L6-v2

（出處：Section 4、4.1、4.3，Table 4、5，p. 5–8）

### 分析方法
Spearman 相關分析（Split-half 信度 $\rho_{hh}$ 與 Human-LLM 一致性 $\rho_{hl}$）、定性與定量分數跨模型／跨資料集的平均值比較、消融對比。（Section 4.1–4.4，p. 6–8）

## 主要發現

> [!success] 重點
> **Ad-LLM 在信任與滿意度上全面超越 Ad-Chat**（信任度最高提升 62.9%）；**Ad-Chat 點擊率略高（+6.5%），但會產生嚴重事實錯誤**；廣告植入數量 $k$ 越多，回答品質與信任度會單調下滑。

### Ad-LLM 全面超越 Ad-Chat
- **整體定性分數**：最佳 Ad-LLM 方案（GIR-R／GIR-P）比 Ad-Chat：
  - MT-Human 高 **14.8%**（74.70 vs. 65.10）
  - LM-Market 高 **15.6%**（73.73 vs. 63.81）
  - CA-Prod 高 **15.64%**（58.41 vs. 50.51）
- **關鍵構面**：Ad-LLM 比 Ad-Chat 最高提升 Accuracy **39.8%**、Personality **89.3%**、Trust **62.9%**（例如 CA-Prod 上，Trust 從 22.66 升到 36.92，Personality 從 25.03 升到 47.39）。
- **原因**：Ad-Chat 的 System Prompt 會迫使 LLM 扮演「推銷員（Salesman-like role）」，嚴重破壞客觀度與信任。
- 出處：Section 4.1, Table 3, p. 6

### Ad-Chat 點擊率較高，但事實正確性極差
- 在 CA-Prod（搜尋引擎情境）中，Ad-Chat 的 CTR 達 **42.02%**，比 GIR-R 的 35.23% 高約 **6.5%**。
- **案例分析**：詢問「如何從蘇黎世中央車站到 Sihlcity 購物中心」——
  - **Ad-Chat**：推薦搭乘 Megabus（跨國長途巴士，蘇黎世市區根本沒營運），產生嚴重事實錯誤。
  - **GIR-R**：給出精確的 13/14 號路面電車指引（10–15 分鐘），並自然推薦 Citymapper 交通 App，廣告輕量且相關。
- 出處：Section 4.1, Table 2、Figure 2, p. 6–7

### 廣告密度 $k$ 增加帶來品質—密度權衡（Quality-Density Trade-off）
- 隨著 $k \in \{1, 2, 3, 4, 5\}$ 增加，Accuracy、Naturalness、Trust、Personality 全部**單調下降**。
- **Click 點擊意願呈非單調變化**：$k=2, 3$ 時因曝光增加而略微上升，但 $k$ 過大時，整體回答吸引力下滑，點擊意願也隨之下降。
- 出處：Section 4.1, Figure 3, p. 6–7

### 真人與 LLM 評審高度一致
- 118 位真人受試者的 Split-half 信度 $\rho_{hh} = 0.84$
- 真人平均分與 GPT-4.1-mini 評審分數的相關係數 $\rho_{hl} = 0.73$
- ⇒ 證實 LLM 評審具備高度可信度
- 出處：Section 4.2，p. 6

### 重寫（Rewriting）階段對自然度與信任至關重要
- 無重寫的 **GI-R** 在定量 Cosine 相似度指標上表現較好（高出 2.0%–5.5%），但在定性 **Naturalness** 上嚴重退化（比 GIR-R 低最多 **25.8%**）。
- 原因：直接插入廣告句太生硬，必須經過 Response Rewriter 重寫，才能建立上下文流暢性與信任感。
- 出處：Section 4.3，p. 7–8

### 運算成本與延遲

| 方案 | 整體 Token 消耗 | 備註 |
| :--- | :--- | :--- |
| GI-R | 192–566 Token | 成本最低 |
| GIR-R / GIR-P | 889–1,632 Token | 因加入 Response Rewriter，約比 GI-R 多 2 倍 Output Token、10 倍 Input Token |
| Ad-Chat | Input Token 為其他方案的 5–25 倍 | 因多階段 Agent 呼叫 |

（出處：Section 4.4, Table 6, p. 8）

## 限制與未來方向

### 作者承認的限制
- **資料集規模與主題數量偏小**：例如 MT-Human 只有 10 個查詢，CA-Prod 只有 120 個查詢。（Section 3.1、6，p. 4–5、9）
- **真人受試者規模仍有擴充空間**：實驗樣本僅 118 人。（Section 4.2、6，p. 6、9）

### 未來研究方向
1. **擴展資料集規模與涵蓋領域**：發布更新版 GEM-Bench 基準。（Section 6，p. 9）
2. **深入研究 AI 商業標示的影響**：探討 AI 搜尋中廣告標示（Disclosure Design，如「贊助」標籤）對使用者接受度與信任的干擾效應。（Section 7，p. 9）
3. **拍賣機制設計**：探索平台端結合廣告信任度與歷史可靠性的 Quality-based Bidding 拍賣機制設計。（Section 7，p. 9）
